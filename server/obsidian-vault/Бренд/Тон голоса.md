# Тон голоса бренда

Мы пишем для технических специалистов, но избегаем жаргона без объяснений.

- Используем [[Терминология|нашу терминологию]] из словаря.
- ==Никогда== не используем слово "дешёвый" — заменяем на "доступный".
- #тон должен быть уверенным, но не агрессивным.
