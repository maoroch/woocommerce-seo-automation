# 🛒 WooCommerce SEO Optimizer (полуавтоматическая версия)

## 📌 Overview

WooCommerce SEO Optimizer — инструмент для массовой SEO-оптимизации товаров в e-commerce проектах в **полуавтоматическом режиме**.

Пользователь (один) экспортирует товары в JSON, отправляет во внешний Claude (или другую LLM), получает изменённый JSON, валидирует и применяет изменения через WooCommerce API.

> **Ключевое отличие:** без встроенного AI Engine, но с мощной валидацией и контролем HTML-контента.

## 🧠 Основные модули

### 1. Bulk Export / Import

**Экспорт товаров в JSON:**
- Выборка по категории, ID (до 50 товаров за раз)
- Поддерживаемые поля: `id`, `sku`, `title`, `meta_title`, `meta_description`, `description` (HTML), `short_description` (HTML), `images[]`, `categories`, `tags`

**Импорт JSON:**
- Валидация схемы (Zod)
- Preview изменений (diff)
- Подтверждение перед записью
- Автоматический бекап

### 2. Content Analyzer

- Проверка длины title (50–60) и meta description (120–160)
- Наличие ключевых слов
- Валидация HTML (закрытые теги, alt у изображений)
- SEO Score (0–100)

### 3. HTML & Structure Control

- Проверка H1 в описании
- Валидация атрибутов изображений
- Минимальная длина контента (300 символов)
- Безопасные манипуляции только через Claude

### 4. Валидация JSON перед импортом

**Zod-схема ограничивает поля:**
- Разрешены: `id`, `title`, `meta_title`, `meta_description`, `description`, `short_description`, `images`
- Запрещены: `sku`, `price`, `permalink`, системные мета-поля
- Проверка типов данных и существования ID

### 5. Preview + Diff + Бекап

- Таблица изменений (старые vs новые значения)
- Подсветка различий
- Автоматический JSON-бекап перед импортом
- Откат через `rollback --latest`

### 6. Работа с HTML

- Экспорт сохраняет HTML как есть
- Проверка валидности перед импортом
- Рекомендация: обработка одного товара за раз для сложных случаев

## 🤝 Human-in-the-Loop (HITL) — ключевой принцип

В отличие от полностью автоматических SEO-плагинов, данный инструмент строится вокруг **человека-контролёра**:

- Все изменения, предложенные AI (Claude), проходят **визуальную проверку** перед записью.
- Пользователь видит точный diff по каждому товару и полю.
- Решение о применении изменений принимает **только человек**.
- Возможность **отката** сохраняет HITL-страховку на случай пропущенной ошибки.

Это даёт:
- Безопасную работу с HTML (таблицы, изображения).
- Контроль над SEO-стилем (Claude может нагаллюцинировать, человек отсекает).
- Отсутствие «чёрного ящика» — вы всегда знаете, что и почему изменилось.

## ⚠️ Риски и их митигация

| Риск | Вероятность | Решение |
|------|-------------|---------|
| Claude ломает HTML | Средняя | Strict промпт, diff, валидация |
| Изменение системных полей | Низкая | Zod-схема |
| Потеря данных | Низкая | Бекап перед записью |
| Hallucination | Низкая | Обработка по одному товару |

## 🧪 Примеры команд

```bash
# Экспорт товаров
npm run export -- --ids=10,11,12 --out=data/for-claude.json

# Предпросмотр
npm run preview -- --file=claude-output.json

# Импорт
npm run import -- --file=claude-output.json --yes

# Откат
npm run rollback -- --latest
```
