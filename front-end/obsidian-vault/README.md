# Obsidian Vault — контекст для AI

Положи сюда `.md`-файлы из своей базы знаний Obsidian (или поддиректории с
вложенными заметками — рекурсивный обход поддерживается).

## Как это используется

При генерации AI-предложений (через дашборд или Worker) можно подключить
содержимое заметок как **дополнительный контекст** — стиль бренда,
терминологию, особенности категорий товаров, требования к описаниям и т.д.
Эти заметки добавляются в системный промпт перед обращением к AI.

## Формат

- Обычные `.md` файлы (с YAML frontmatter или без — frontmatter удаляется
  автоматически).
- Obsidian-специфичный синтаксис (`[[wikilinks]]`, `![[embeds]]`, `#tags`)
  очищается перед отправкой в AI, чтобы не путать модель служебными символами.
- Вложенные папки поддерживаются — структура vault сохраняется в списке
  заметок (`Категории/Логгеры.md` отображается как `Категории/Логгеры`).

## Рекомендации

- Держи заметки сфокусированными: "Тон голоса бренда", "Шаблон описания для
  категории Логгеры", "Список запрещённых слов" и т.д. — отдельными файлами.
  Так в дашборде можно выбрать только релевантные для конкретного товара.
- Очень большие заметки (>20 000 символов) будут автоматически обрезаны —
  держи их компактными.
- Этот каталог **не синхронизируется** с WooCommerce и не публикуется —
  только читается локально для построения промптов.

## Пример структуры

```
obsidian-vault/
├── Бренд/
│   ├── Тон голоса.md
│   └── Запрещённые слова.md
├── Категории/
│   ├── Логгеры.md
│   └── Кабели.md
└── SEO/
    └── Чеклист meta-описаний.md
```
